## 4. Як оцінюється

Кожен модуль — **100 балів**. Підсумкова оцінка — середнє двох модулів.

| Складова | Балів |
|---|---|
| Практичні на заняттях | 50 |
| Активність, участь в обговоренні | 10 |
| Індивідуальна робота із захистом | 40 |

### Практична робота — до 8 балів

| Балів | За що |
|---|---|
| 3 | **Є видимий слід до кінця пари**: коміт, файл у чаті або показ екрана |
| 3 | Завдання виконане по суті |
| 2 | Ви пояснюєте, що саме зробили |

Бали ставляться **на занятті**. Зробили на парі — домашнього немає.
Не були або не працювали — те саме завдання стає домашнім.

### Індивідуальна робота — до 40 балів

| Балів | За що |
|---|---|
| 10 | Робота повна і здана вчасно |
| 10 | Предмет розкрито: що це, для кого, яку задачу розвʼязує |
| 8 | Є власний приклад — код або конкретний розбір |
| **12** | **Усний захист: пояснюєте своє рішення й відповідаєте на питання** |

**Без захисту робота не зараховується**, скільки б у ній не було зроблено.

### Якщо нічого не зробили

Є запасний вихід: обираєте **три питання** з переліку свого модуля
й розповідаєте по них усно. Максимум за цим шляхом — **60 балів**.
Це прохідний мінімум, і більше цим шляхом не буває.

Перелік питань викладач дає на першому занятті.

## 5. Про штучний інтелект — чесно

Користуватись **можна**. Заборона все одно не працює, а вміння
користуватись — навичка.

Дві умови:

1. **Зазначайте**, що зроблено з допомогою AI — одним рядком у README роботи.
2. **Ви маєте пояснити кожен рядок.** На захисті питання будуть
   саме по вашому коду.

> Роботу можна зробити з чиєюсь допомогою. **Пояснення — ні.**
> Тому оцінюється не текст, а те, чи ви його розумієте.

## 7. П'ять команд Git, яких вистачить

```bash
git status                  # що зараз змінено
git add .                   # відібрати зміни
git commit -m "опис"        # зафіксувати
git push                    # відправити на GitHub
git log --oneline           # подивитись історію
```

**Коміт із повідомленням `fix` або `123` — це втрачена інформація.**
Пишіть, що саме зробили: `додано розбір журналу`, `виправлено регулярку для дати`.

Один коміт наприкінці семестру на всі роботи — не зараховується.
Історія має показувати, як ви працювали.
