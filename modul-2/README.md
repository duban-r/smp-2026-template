# Індивідуальна робота модуля 2 — «Мова всередині застосунку»

**До 40 балів. Захист на тижні 17.**

Оберіть **один** із двох варіантів. Обидва дають однаковий максимум.

---

## Варіант А — есе, 4–6 сторінок

Порівняльний аналіз двох підходів або платформ. Наприклад:

- low-code проти класичної розробки;
- блочні мови проти текстових;
- декларативний опис інтерфейсу проти імперативного;
- дві low-code платформи між собою.

Файл `ese.md` у цій теці.

## Варіант Б — застосунок

Простий робочий застосунок на Tkinter або PyGame: калькулятор,
нотатник, список справ, проста гра.

Вимога одна: **запускається, і ви можете пояснити свій код**.

Плюс `poyasnennya.md` — півсторінки: **які міні-мови використані
всередині** — опис макета, опис подій, шаблони рядків, запити.
