# Індивідуальна робота модуля 1 — «Предметна мова під мікроскопом»

**До 40 балів. Захист на тижні 9.**

Це **основна форма контролю модуля** — модульної контрольної немає.

Оберіть **один** із двох варіантів. Обидва дають однаковий максимум.

---

## Варіант А — есе, 4–6 сторінок

Обрати одну предметну мову й описати:

1. яку задачу вона розвʼязує і хто її кінцевий користувач;
2. мінімальний робочий приклад коду з поясненням;
3. одне **вдале** й одне **невдале** рішення в її синтаксисі;
4. чим це робилося б без неї та чому було б гірше.

Файл `ese.md` у цій теці.

## Варіант Б — міні-проєкт

Три маленькі роботи в одному місці:

- скрипт із регулярними виразами;
- набір SQL-запитів;
- README у Markdown.

Плюс `poyasnennya.md` — півсторінки: яку задачу розвʼязує кожна
з цих мов і чому там незручна мова загального призначення.

---

## Теми на вибір

SQL · регулярні вирази · Markdown · HTML і CSS · YAML · JSON · Git ·
LaTeX · BPMN · Gherkin · Dockerfile · Makefile · **власна пропозиція**

Тему оголосити до **тижня 5**, щоб не було десяти однакових робіт.

## Як оцінюється

| Балів | За що |
|:---:|---|
| 10 | Робота повна і здана вчасно |
| 10 | Предмет розкрито: що це, для кого, яку задачу розвʼязує |
| 8 | Є власний приклад — код або конкретний розбір |
| **12** | **Усний захист: пояснюєте своє рішення й відповідаєте на питання** |

**Без захисту робота не зараховується**, скільки б у ній не було зроблено.

Захист — 5 хвилин показу + питання. Питання будуть **тільки по вашій роботі**:

- чому обрали саме цю мову;
- що відбувається в конкретному рядку вашого прикладу;
- де межа цієї мови і що робили б, упершись у неї.

Готуватись окремо не треба. Треба **розуміти те, що здаєте**.
