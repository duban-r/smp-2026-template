## Крок 1. Читаємо незнайомі мови (40 хв)

Відкрийте `praktyka/14-dopovid/chytannia.md`. Шість фрагментів: GitHub Actions, Terraform, Dockerfile,

Відповіді — унизу файлу, у форматі:

```

```

✔ Для кожного питання — ✅ або ❌ з підказкою, куди дивитись. Мінімум — **9 з 12**.

Як читати незнайому мову — ті самі три питання, що весь семестр:
**яку задачу розвʼязує** · **що описує — кроки чи результат** · **де межа**.
Більшість відповідей виводиться з цього, а не з довідника.

<details>
<summary>Підказка: якщо застрягли на фрагменті</summary>

- GitHub Actions: `on` — коли, `jobs` — що, `steps` — по порядку. Розклад `cron` — п'ять полів: хвилина, година, день місяця, місяць, **день тижня** (1 — понеділок), час — UTC.
- Terraform: декларативна, як SQL. Пам'ятаєте, що робить оптимізатор із запитом?
- Docker: кожен рядок — шар, і шари кешуються. Що змінюється частіше: бібліотеки чи ваш код?
- Gherkin: «Припустимо — Коли — Тоді» = дано, дія, перевірка.
- GraphQL: клієнт сам пише, які поля хоче.
- Makefile: «ціль: джерело» і команда, як із джерела отримати ціль.

</details>

## Якщо щось пішло не так

| Що бачите | Що це означає | Що робити |
|---|---|---|
| `⏳ N: немає відповіді` | рядок не у форматі | `N: літера — бо …`, літера латиницею |
| `← допишіть одне речення` | лише літера | після літери — тире й пояснення |
| «у заголовку немає назви мови» | лишились `…` | `# Доповідь: Terraform` |
| «приклад — 30 рядків» | забагато для 5 хвилин | залиште найважливіші 5–15 |
| «немає жодного посилання» | розділ «Джерела» порожній | посилання на офіційну документацію |
| мою тему вже взяли | хтось написав раніше | оберіть іншу зі списку або запропонуйте свою |
