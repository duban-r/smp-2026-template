# Робота 14. Доповідь про предметну мову

Теми 14–15 · до **8 балів** · здати **до кінця пари**

## Умова

**5 хвилин**, одна предметна мова на вибір. Тему оголошують заздалегідь,
щоб не було повторів.

Структура — три знайомі питання:

1. яку **задачу** мова розвʼязує і хто її кінцевий користувач;
2. **приклад** коду з поясненням, 5–10 рядків;
3. де її **межа** — що нею робити не варто.

Можна зі слайдами, можна без. Живий приклад — навіть краще.

## Теми на вибір

Terraform · GitHub Actions · Docker Compose · Kubernetes YAML ·
Solidity · Gherkin · Mermaid · PlantUML · GraphQL · LaTeX ·
Ansible · Makefile · CSS Grid · Power Query M · DAX · Vega-Lite ·
Nix · власна пропозиція

`dopovid.md` або слайди у цій теці.
