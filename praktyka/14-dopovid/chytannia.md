# Читаємо незнайомі мови

Шість фрагментів сучасних предметних мов. Більшість ви бачите вперше — це нормально:
читайте трьома питаннями (задача · що простим · де межа) і здоровим глуздом.

Під кожним фрагментом — два питання з варіантами. **Відповіді** — у розділі внизу,
у форматі `1: c — бо …` (літера латиницею й одне речення «чому»).

Перевірка: `python praktyka/14-dopovid/perevir.py`

## Фрагмент 1 — GitHub Actions

```yaml
name: Тести
on:
  pull_request:
    branches: [master]
  schedule:
    - cron: "0 6 * * 1"
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: python -m pytest
```

**1.** Коли запуститься цей процес?
a) при кожному push у будь-яку гілку · b) щодня о 6:00 · c) при pull request у master і щопонеділка о 6:00 за UTC · d) лише вручну

**2.** Що станеться, якщо `pytest` знайде помилку?
a) GitHub відкотить коміт · b) крок стане червоним, а pull request покаже ❌ · c) нічого · d) гілку буде видалено

## Фрагмент 3 — Dockerfile

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["python", "main.py"]
```

**5.** Навіщо `requirements.txt` копіюють окремо й раніше за решту коду?
a) так вимагає Docker · b) так красивіше · c) щоб образ був меншим · d) щоб після зміни коду не перевстановлювати бібліотеки — цей крок береться з кешу

**6.** Коли виконується рядок `CMD`?
a) під час збирання образу · b) під час запуску контейнера · c) разом із `COPY` · d) ніколи, це коментар

## Фрагмент 4 — Gherkin

```gherkin
# language: uk

  Сценарій: запис після дедлайну
```

**7.** Для рядка «Коли студент натискає «Записатись»» програміст ще не написав коду кроку. Що буде під час запуску?

**8.** Що робить рядок, який починається з «Тоді»?
