# Робота 11. Події

Тема 11 · до **8 балів** · здати **до кінця пари**

## Умова

Калькулятор або нотатник — на вибір. Обовʼязково:

1. щонайменше **три різні події**, і серед них хоча б одна через `bind`;
2. `Enter` у полі працює так само, як натискання головної кнопки;
3. `Escape` очищає форму;
4. обробка помилки введення — програма **не падає** на некоректних даних;
5. `StringVar` хоча б в одному місці.

## Що здати

`kalkulyator.py` або `notatnyk.py` + допишіть у цей файл таблицю:
подія → що робить → чому саме така.

## ⭐ Із зірочкою

Додати `trace_add`, щоб щось оновлювалось **під час набору**,
без натискання кнопок. Або: гарячі клавіші `<Control-s>` і `<Control-o>`.
