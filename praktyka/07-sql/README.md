<details>
<summary>Підказка 1: який оператор для чого — словами</summary>

- Тривалість зберігається в **мілісекундах**. У секундах — поділити.
- «Починається на A» і «містить слово» — оператор `LIKE` зі знаком `%`. Де стоїть `%` — там «будь-що».
- «Сім найбільших» — відсортувати за спаданням і взяти перші сім.
- «Польща або Чехія» — дві повні умови через `OR`, або перелік через `IN`. Як саме
  записані країни в базі — подивіться самі.
- «Порожнє поле» в базі — це `NULL`. З ним не порівнюють через `=`.
- «Без повторів» — одне слово одразу після `SELECT`.
- «Березень 2025» — дати зберігаються текстом виду `2025-03-31 00:00:00`.

</details>

<details>
<summary>Підказка 2: шматки запитів — якщо після першої підказки 10 хвилин не зрушили</summary>

- пункт 8: дата **не менша** за `'2025-03-01'` і **менша** за `'2025-04-01'`

</details>

## Якщо щось пішло не так

| Що бачите | Що це означає | Що робити |
|---|---|---|
| `Не знайдено …chinook.db` | скрипт запущено не з кореня репозиторію | `cd ~/smp-2026`, потім `python praktyka/07-sql/perevir.py` |
| `no such table: tracks` | таблиці названі інакше | **однина з великої**: `Track`, `Customer`, `Invoice` |
| `no such column: …` | стовпець названий інакше | `SELECT * FROM <таблиця> LIMIT 1` — подивитись назви |
| `near "…": syntax error` | пропущена кома між стовпцями або лапка | рядки — в **одинарних** лапках: `'Canada'` |
| `кілька запитів через «;»` | під одним `-- N.` два запити | лишіть один, решту закоментуйте `--` |
| ⏳ хоча запит написаний | рядок `-- N.` змінено або видалено | поверніть рядок `-- N.` точно як у шаблоні |
| `рядки ті, але порядок не той` | немає `ORDER BY` або не той напрям | `ASC` — за зростанням, `DESC` — за спаданням |
| fiddle не бачить файл | файл не завантажено | **Load DB…** → `data/chinook.db`; або `python -m sqlite3 data/chinook.db` |
| `git checkout` перезаписав мій `sql-1.sql` | ви почали раніше за крок 0 | `git log -- praktyka/07-sql/sql-1.sql`, потім `git checkout <коміт> -- praktyka/07-sql/sql-1.sql` |
