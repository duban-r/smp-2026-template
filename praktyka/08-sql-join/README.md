# Робота 8. SQL: обʼєднання і агрегація

Тема 8 · до **7 балів** · здати **до кінця пари**

## Умова

База та сама: `../../data/chinook.db`. Файл `sql-2.sql`.

1. Треки з назвою альбому й імʼям виконавця (три таблиці).
2. Скільки треків у кожному жанрі — **назва** жанру, не `GenreId`.
3. Топ-10 клієнтів за сумою покупок.
4. Виконавці, у яких **більше 5 альбомів**.
5. Виконавці **без жодного альбому**.
6. Середня тривалість треку по кожному жанру, у хвилинах, за спаданням.
7. ⭐ Країна, у якій магазин заробив найбільше.

Мають бути використані `JOIN`, `GROUP BY` і `HAVING`.

## Підказка до пункту 5

Прийом називається **LEFT JOIN + IS NULL** — так знаходять те, чого немає.
Звичайний `JOIN` такі рядки викидає.
