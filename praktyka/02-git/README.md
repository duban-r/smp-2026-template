# Робота 2. Git

Тема 2 · до **7 балів** · здати **до кінця пари**

## Умова

1. Пройти перші **4 рівні** тренажера
   [learngitbranching.js.org](https://learngitbranching.js.org) — там є українська.
2. Створити цей репозиторій через **Use this template**, зробити публічним.
3. Заповнити своє імʼя в головному `README.md`.
4. Зробити **щонайменше 3 коміти з осмисленими повідомленнями**.
5. Створити гілку, зробити в ній зміну, злити в `main`.
6. Скинути посилання на репозиторій у чат заняття.

## Що здати

Скріншот тренажера — файл `trenazher.png` у цій теці.
Решта перевіряється по історії вашого репозиторію.

## ⭐ Із зірочкою

Увімкнути GitHub Pages, щоб README відкривався як сторінка.
Або: написати `.gitignore` під Python і пояснити кожен рядок.
