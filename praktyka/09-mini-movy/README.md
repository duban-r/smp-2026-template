# Робота 9. Міні-мови всередині Python

Тема 9 · до **8 балів** · здати **до кінця пари**

## Умова

Файл `mini-languages.py` — скрипт, який виводить звіт про файли в теці
й використовує **щонайменше пʼять різних міні-мов**:

1. `glob` — знайти файли за шаблоном;
2. **формат рядків** — таблиця з вирівнюванням, розміри в мегабайтах
   із двома знаками;
3. `strftime` — дата зміни у форматі `дд.мм.рррр`;
4. **регулярний вираз** — відібрати файли з іменем за шаблоном;
5. **зріз** — показати тільки перші 10 результатів.

## Що здати

`mini-languages.py` + допишіть у цей файл нижче:
**яку міні-мову де використано і що вона робить простим**.

## ⭐ Із зірочкою

Додати `argparse` із двома параметрами — шлях і шаблон.
Це шоста міні-мова, і саме нею користуються всі консольні утиліти.
