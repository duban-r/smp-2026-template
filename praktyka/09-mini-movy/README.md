## Крок 3. Звіт на пʼяти міні-мовах (45 хв)

`mini-languages.py` уже вміє все, крім головного: у пʼяти місцях стоїть `...` — там має бути
рядок або число на одній із міні-мов. Програма друкує таблицю **10 найбільших файлів** теки:
імʼя, розмір у КБ, дата зміни — і скільки файлів мають у назві дату.

| Місце | Міні-мова | Що має робити |
|---|---|---|
| 1 | шаблон імені `glob` | узяти **все**, що є в теці |
| 2 | зріз | залишити **10** перших (найбільших) |
| 3 | формат рядків | імʼя ліворуч у полі **30**, КБ праворуч у полі **8** з **одним** знаком після коми |
| 4 | формат дати | `дд.мм.рррр` |
| 5 | регулярний вираз | дата в назві файлу у вигляді `рррр-мм-дд` (рівно 4, 2 і 2 цифри) |

Запуск на будь-якій теці:

<details>
<summary>Підказка 1: де шукати синтаксис</summary>

- `glob`: `*` — будь-що, `?` — один символ.
- зріз: `[початок:кінець]`, початок можна не писати.
- формат: `:<30` — ліворуч у полі 30; `:>8.1f` — праворуч у полі 8, число з одним знаком.
- дата: `%d` день, `%m` місяць, `%Y` рік **чотирма** цифрами.
- регулярка — тиждень 5: `\d{4}` — рівно чотири цифри.

</details>

<details>
<summary>Підказка 2: якщо після першої 10 хвилин не зрушили</summary>

- місце 1: `"*"`; місце 2: `fayly[:10]`
- місце 3: `f"{imia:<30}{kb:>8.1f}  {data}"`
- місце 5: три групи цифр через дефіс — `\d{4}-\d{2}-\d{2}`

</details>

## Якщо щось пішло не так

| Що бачите | Що це означає | Що робити |
|---|---|---|
| `No module named 'tkinter'` | Python встановлено без Tk | перевстановити Python з python.org, галочка **tcl/tk and IDLE** |
| `list indices must be integers or slices, not ellipsis` | у зрізі лишилось `...` | місце 2: `[:10]` |
| `Invalid format specifier` | у f-рядку лишилось `...` або зайвий пробіл | місце 3: `{imia:<30}` — без пробілів усередині |
| у таблиці порожньо | шаблон `glob` нічого не знайшов | місце 1: `"*"` |
| дата `2026-10-01` | коди дати не в тому порядку | `%d.%m.%Y` |
| «З датою в назві: 6» | вираз пропускає `2026-9-1` | рівно `\d{4}-\d{2}-\d{2}` |
| «З датою в назві: 4» | рахуєте серед `top` | рахуйте серед `fayly` — так у заготовці |
| `FileNotFoundError: perevir` | запуск не з кореня репозиторію | `cd ~/smp-2026` |
| вікно не закривається з терміналу | `mainloop` чекає подій | закрити хрестиком або кнопкою «Закрити» |
