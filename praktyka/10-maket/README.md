## Крок 2. Форма через grid (30 хв)

Форма реєстрації — однакова для всіх трьох файлів:

- заголовок **«Реєстрація»**;
- чотири **підписи з полями**: Імʼя, Пошта, Телефон, Пароль — поле пароля показує `•` (`show="•"`);
- прапорець **«Погоджуюсь з умовами»**;
- кнопки **«Зареєструватись»** і **«Скасувати»** — **внизу праворуч**.

Поля мають стояти **в одну колонку**, кожен підпис — **ліворуч** від свого поля.

Починайте з `form_grid.py`: таблиця — найприродніша мова для форми.

```

python praktyka/10-maket/perevir.py grid
```

✔ `perevir.py` на мить відкриває вашу форму, вимірює, де що стоїть, і пише ✅ або список зауважень.

<details>
<summary>Підказка 1: як думати в grid</summary>

- Намалюйте форму таблицею на папері: рядки 0…6, стовпці 0 і 1. Підписи — у стовпці 0, поля — у стовпці 1.
- Заголовок займає обидва стовпці — для цього є параметр, що «розтягує на кілька стовпців».

<details>
<summary>Підказка 2: шматки коду — якщо після першої підказки 10 хвилин не зрушили</summary>


Заголовок: `.grid(row=0, column=0, columnspan=2)`. Рамка з кнопками: `.grid(row=6, column=0, columnspan=2, sticky="e")`,

## Крок 3. Та сама форма через pack (25 хв)

`form_pack.py` — **лише** `pack`. Потік не знає стовпців, тому:

- кожен рядок «підпис + поле» — окрема `tk.Frame`, усередині — `pack(side="left")`;
- щоб поля стали в колонку, усім підписам дайте **однакову ширину** (`width=…` у символах) і вирівнювання тексту.

```
python praktyka/10-maket/perevir.py pack
```

<details>
<summary>Підказка</summary>

```python
ryadok = tk.Frame(vikno)
ryadok.pack(fill="x", padx=10, pady=2)
tk.Label(ryadok, text="Імʼя:", width=10, anchor="e").pack(side="left")
tk.Entry(ryadok).pack(side="left", fill="x", expand=True)
```

</details>

## Якщо щось пішло не так

| Що бачите | Що це означає | Що робити |
|---|---|---|
| `cannot use geometry manager "grid" inside "."` | два менеджери в одному контейнері | один контейнер — один менеджер; другий — усередині `tk.Frame` |
| вікно порожнє | елемент створено, але не розміщено | після `tk.Label(…)` потрібен `.grid(…)`, `.pack(…)` або `.place(…)` |
| `'NoneType' object has no attribute` | `pole = tk.Entry(…).grid(…)` — `grid` повертає `None` | спершу `pole = tk.Entry(…)`, потім окремим рядком `pole.grid(…)` |
| «поля не в одну колонку» (pack) | підписи різної довжини | однакова `width` у всіх підписів |
| «поля не в одну колонку» (grid) | поля в різних `column` | усі поля — `column=1` |
| «кнопки — праворуч» | кнопки притиснуті ліворуч | рамці з кнопками — `sticky="e"`, кнопкам — `side="right"` |
| «підписи й поля мають стояти через …» | у файлі не той менеджер | у `form_pack.py` — лише `pack` тощо |
| `perevir` пише «форма не закрилась» | у файлі `input()` або нескінченний цикл | приберіть їх: форма має лише показуватись |
