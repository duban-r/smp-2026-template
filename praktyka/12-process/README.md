# Робота 12. Формалізація процесу

Тема 12 · до **8 балів** · здати **до кінця пари**

## Умова

Оберіть реальний процес, який знаєте: замовлення в кафе, здача сесії,
оформлення перепустки, повернення товару, запис до лікаря.

Файл `process.md`:

1. опис **природною мовою**, 5–8 речень;
2. **учасники** і що робить кожен;
3. щонайменше **5 правил** у формі `When … / If … / Then …`;
4. **схема процесу** — mermaid прямо в `.md` або скріншот з [draw.io](https://draw.io);
5. позначити, **де в цьому процесі знадобився б SQL, а де регулярний вираз**.

## Приклад правила

    When   натиснуто кнопку «Оформити»
    If     сума замовлення більша за 5000
    Then   надіслати на погодження керівнику
    Else   оформити автоматично

## ⭐ Із зірочкою

Зареєструватись у безкоштовному середовищі (Power Automate або Camunda)
і **зібрати цей процес насправді**. Це найближче до реальної роботи
бізнес-аналітика, що є в курсі.
