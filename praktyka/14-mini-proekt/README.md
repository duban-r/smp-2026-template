# Робота 14. Міні-проєкт однією предметною мовою

Тема 14 · до **8 балів** · практика — друга пара й початок третьої ·
розбір і бали — з середини третьої пари

## Задача

Зробіть **маленький, але справжній** проєкт однією з предметних мов зі списку нижче.
Не великий і не складний: 40–60 рядків або одна сторінка. Головна вимога інша:
проєкт має використовувати **особливість саме цієї мови** — те, чого в Python так просто не зробиш.
Для кожної теми в таблиці ця особливість названа.

## Що має бути наприкінці

- у теці `praktyka/14-mini-proekt/` — **файл(и) проєкту** вашою мовою (`.yml`, `.sql`, `.mmd`, `.tex`, `.svg`…);
- `proekt.md` заповнений: що робить проєкт, як його запустити або подивитись, **результат**
  (скриншот або вивід), **особливість мови** своїми словами, межа;
- `perevir.py` показує «усе на місці», усе на GitHub, **номер теми — у чаті**.

**Мінімум для зарахування** — проєкт запускається або відкривається, у ньому є обовʼязкова
особливість мови з таблиці, `proekt.md` заповнений, `perevir.py` без ❌.

**Контрольні точки:** 12:20 — номер теми в чаті · 13:00 — мінімальний приклад працює
(скриншот у чат) · 14:00 — `perevir.py` без ❌ · 14:15 — `push`, стоп і розбір.

Застрягли більше ніж на 5 хвилин — напишіть у чат номер кроку
й **скопійований** текст помилки.

> **Навчаєтесь асинхронно або не змогли бути на парі?** Ті самі кроки, дедлайн — до початку
> наступного заняття (21.12, 10:30). Номер теми напишіть у чат **якнайшвидше** — теми не повторюються.
> Пояснення особливості мови в `proekt.md` замінює для вас показ на розборі.
