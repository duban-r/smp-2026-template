## Крок 2. Гра (60 хв)

`hra.py` — заготовка: вікно, годинник, шрифт і цикл кадрів уже крутяться. Додайте пʼять речей:

1. **гравець** — `pygame.Rect`, рухається клавішами (стрілки або WASD) і не виходить за екран;
2. **обʼєкт, що рухається сам** — ворог, монетка, мʼяч: щокадру змінює координати;
3. **зіткнення з наслідком** — `colliderect`, і після нього щось стається: +1 до рахунку, −1 життя, кінець гри;
4. **рахунок на екрані** — текст із числом;
5. **60 кадрів на секунду** — `hodynnyk.tick(60)` уже є, не зламайте.

```

python praktyka/13-hra/perevir.py
```

✔ `perevir.py` запускає гру без вікна на 4 секунди, сам «натискає» стрілку вправо, надсилає QUIT

Порада з демо: **по одному кроку, і після кожного — запуск**. Спершу квадрат гравця, потім рух,
потім ворог, потім зіткнення, потім текст.

<details>
<summary>Підказка 1: що де в циклі</summary>

- Гравець і ворог створюються **до** циклу: `gravets = pygame.Rect(300, 400, 40, 40)`.
- Клавіші — у блоці «ввід»: `klavishi = pygame.key.get_pressed()`, далі `if klavishi[pygame.K_LEFT]: …`.
- Рух ворога, межі, зіткнення — у блоці «оновити стан».
- Малювати — **після** `fill`, інакше `fill` зітре намальоване.
- Не виходити за екран: `gravets.clamp_ip(ekran.get_rect())`.

</details>

## Якщо щось пішло не так

| Що бачите | Що це означає | Що робити |
|---|---|---|
| `pip install pygame` падає з «Failed to build» | для вашого Python немає готового `pygame` | `python -m pip install pygame-ce` |
| `No module named 'pygame'` | не встановлено або встановлено в інший Python | `python -m pip install pygame-ce` — саме тим `python`, яким запускаєте |
| `pygame-ce` не ставиться взагалі | дуже рідко; старий pip | `python -m pip install --upgrade pip`, потім ще раз; не вийшло — гра на `tkinter.Canvas` з `after()` і пояснення в чаті |
| вікно не закривається хрестиком | немає обробки `QUIT` | `if podiia.type == pygame.QUIT: pratsiuie = False` |
| гравець лишає слід | малюєте до `fill` або `fill` прибрали | порядок: `fill` → малювати → `flip` |
| гравець не рухається повільно | `rect.x += 0.5` — Rect зберігає цілі (передбачення D) | швидкість ≥ 1 або окрема змінна `float` для координати |
| рахунок росте на десятки за одне зіткнення | зіткнення триває кілька кадрів | після зіткнення перемістіть ворога або поставте паузу |
| текст не видно | `blit` до `fill` або колір збігся з фоном | `blit` після `fill`, білий колір на темному фоні |
| `perevir`: «без клавіш екран не змінюється» | ворог рухається лише разом із гравцем | рух ворога — у «оновити стан», без умов на клавіші |

Скріншот → `scratch.png`. У `ponyattia.md` — 3 речення: що вийшло швидше, що незручніше, і чому.

**⭐4. Своя мова опису рівнів (30+ хв).** Справжня задача: рівень — це **текст**, а не код. `riven.txt`:


файл і перетворює кожен символ на `Rect` клітинки 40×40; гравець не проходить крізь стіни, монетки
зникають і дають очки. ✔ Змінили `riven.txt` — змінився рівень, код не чіпали. У `ponyattia.md` —
2–3 речення: хто кінцевий користувач вашої мови і де її межа.
