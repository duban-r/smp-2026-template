# Робота 5. Регулярні вирази: пошук

Тема 5 · до **7 балів** · здати **до кінця пари**

## Умова

Файл `regex-1.md`. Для кожного пункту — вираз, приклад тексту,
на якому він працює, і один рядок пояснення.

1. Український мобільний телефон у трьох форматах.
2. Дата `дд.мм.рррр` — **із перевіркою, що місяць не більший за 12**.
3. Адреса електронної пошти.
4. Ідентифікатор змінної Python: літера або `_`, далі літери, цифри, `_`.
5. Рядок **тільки** з великих латинських літер, 3–8 символів.
6. Усі слова, довші за 8 літер.

Перевіряти на [regex101.com](https://regex101.com), додати посилання
на збережений вираз (кнопка **Save regex**).

## ⭐ Із зірочкою

Пункт 2 — місяць не більший за 12 — вимагає думати, а не згадувати.
Хто зробить без підказки й пояснить логіку, отримає свою задачу
як приклад для наступного курсу.
