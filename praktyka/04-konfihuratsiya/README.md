# Робота 4. Мови конфігурації

Тема 4 · до **7 балів** · здати **до кінця пари**

## Умова

Придумайте застосунок (чат-бот, магазин, гра — байдуже) і опишіть
його налаштування **трьома мовами**. У конфігурації обовʼязково має бути:

- щонайменше **8 параметрів**;
- **вкладений блок** (наприклад, налаштування бази даних);
- **список** щонайменше з трьох елементів;
- параметри різних типів: рядок, число, логічне значення.

## Що здати

- `config.json`
- `config.yaml`
- `config.toml`
- `vysnovok.md` — 3–5 речень: який формат ви обрали б для цього
  застосунку і чому

Файли мають бути валідними — перевірити на [yamllint.com](https://www.yamllint.com).

## ⭐ Із зірочкою

Скрипт на Python, який читає всі три файли й перевіряє,
що вміст **ідентичний**. Це рядків десять.
