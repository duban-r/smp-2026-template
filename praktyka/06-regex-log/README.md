## Крок 3. `log-parser.py` (40 хв)

Файл для розбору — `data/access.log`, **303 рядки**. Формат рядка:

| Поле | Приклад | Де в рядку |
|---|---|---|
| IP-адреса | `172.16.4.101` | на самому початку |
| час | `17/Mar/2026:08:01:26 +0200` | у квадратних дужках `[ ]` |
| метод | `GET` | перше слово в перших лапках |
| шлях | `/catalog.html` | друге слово в перших лапках |
| протокол | `HTTP/1.1` | ⚠️ третє слово в тих самих лапках |
| код відповіді | `200` | три цифри одразу після закривальної лапки |
| розмір, реферер, браузер | … | далі — нам не потрібні |

Напишіть `praktyka/06-regex-log/log-parser.py`, який виводить:

1. скільки рядків **розібрано** і скільки **пропущено**;
2. **топ-5 IP-адрес** за кількістю запитів;
3. скільки запитів кожного **коду відповіді**;
4. усі запити з помилкою **5xx** — час і шлях.

Обовʼязково: **іменовані групи** `(?P<імʼя>...)` і `re.compile`.

⚠️ У файлі **три зіпсовані рядки**. Скрипт не має на них падати — просто пропускайте й рахуйте.

```
python praktyka/06-regex-log/log-parser.py
```

✔ Для самоперевірки: **розібрано 300, пропущено 3**; перший IP у топі має **69** запитів;
різних кодів відповіді — **8**; запитів 5xx — **24**.

Будуйте шаблон **по одному полю**: спершу лише IP — запустили — додали час — запустили…

<details>
<summary>Підказка 1: як будувати шаблон</summary>

- IP: `(?P<ip>\d+\.\d+\.\d+\.\d+)` — ви писали схожий вираз у роботі 5.
- Між полями — «що завгодно, але якнайменше»: `.*?`
- Час: квадратну дужку треба екранувати, а всередині — «усе, крім `]`»: `\[(?P<chas>[^\]]+)\]`
- Метод і шлях — у лапках, через пробіл. Після шляху до закривальної лапки ще є ` HTTP/1.1`:
  «усе, крім лапки» — `[^"]*`.
- Код — три цифри після лапки й пробілу.

</details>

<details>
<summary>Підказка 2: структура скрипта</summary>

```python
import re
from collections import Counter

shablon = re.compile(r"...")
ip = Counter()

with open("data/access.log", encoding="utf-8") as f:
    for ryadok in f:
        m = shablon.search(ryadok)
        if not m:
            ...  # зіпсований рядок
            continue
        ip[m["ip"]] += 1

for adresa, kilkist in ip.most_common(5):
    print(kilkist, adresa)
```

</details>

## Якщо щось пішло не так

| Що бачите | Що це означає | Що робити |
|---|---|---|
| `FileNotFoundError: 'data/access.log'` | скрипт запущено не з кореня репозиторію | `cd ~/smp-2026`, потім `python praktyka/06-regex-log/log-parser.py` |
| `'NoneType' object has no attribute ...` | шаблон не збігся з рядком, а ви звертаєтесь до `m` | спершу `if not m: continue` |
| розібрано 0 рядків | шаблон не збігається ні з чим | прибрати все, крім групи IP, і нарощувати по полю |
| шлях виходить `/catalog.html HTTP/1.1"` | `.*` у шляху жадібний | шлях — `\S+`, далі `[^"]*` до лапки |
| розібрано 303, пропущено 0 | шаблон надто «добрий» — пропускає зіпсовані рядки | вимагайте код із трьох цифр після лапки |
| `UnicodeDecodeError` | файл відкрито без кодування | `open(..., encoding="utf-8")` |
| `KeyError: 'ip'` | немає групи з такою назвою | назва в `m["ip"]` = назва в `(?P<ip>...)` |
| `re.error: unknown extension ?<` | написали `(?<ip>...)` | у Python: `(?P<ip>...)` — з літерою **P** |
